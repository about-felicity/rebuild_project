分镜流水线
接入 demo/storyboard_pipeline：产品图分析 → 剧本扩写 → 场景细化 → 分镜 JSON；可选万相逐镜出图。结果写入当前选中项目的服务端目录，并在「素材库 → 分镜库」中登记。

可从当前项目素材库勾选栅格图片，或本地上传；合计 1–3 张。Vision 会读全部图做策划；Step0 会识别产品主图、可选人物与场景/背景；逐镜生图（Seedream/万相）按「人物→产品→背景」传参考（缺类则省略）。产品棚拍勿放在第一位更易判对。

顺序与上方已选图片列表一致；仅当自动识别不准时改此项。

「一键：分镜并成片」= 跑完分镜与出图后自动调用下方「从分镜生成成片视频」（需 ARK 视频、ffmpeg）。若只想改脚本不出视频，请用左侧「开始生成分镜」。

从磁盘读取 …/storyboard_runs/<run_id>/（含 storyboard_script.md 的条目会标注）。选中后自动填入下方 run id，再点生成成片；无需再走「一句话生成分镜」。

当 storyboard.json 与每镜 frame.image_url 已就绪时，逐镜 Ark 图生视频并用 ffmpeg 拼接，成片写入视频库（需本机 ffmpeg 与 ARK 视频配置）。生成成片时优先使用上方下拉所选。
